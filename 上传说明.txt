对应论文：https://ieeexplore.ieee.org/abstract/document/11614834

1. 解压本压缩包。所有文件均已按仓库根目录准备，没有嵌套文件夹。
2. 在自己的GitHub账号下新建专门仓库；本项目的目标仓库为ShangGuanJianGuo/IB-Power-Control。
3. 打开该仓库，使用Add file → Upload files（空仓库也可使用uploading an existing file链接）。
4. 上传解压后的全部文件，包括.gitignore、.gitattributes、README.md、CITATION.cff等。不要仅把ZIP作为唯一文件上传；GitHub不会自动展开源码压缩包。
5. 填写提交说明，例如Add paper source code and documentation，并提交。若仓库要求通过分支合并，则按仓库要求发起Pull Request。
6. 上传后仓库首页会展示README.md，包含论文链接、引用、代码作用和运行命令。读者按README生成信道、训练权重并运行实验。

本包仅含源码与说明文件，无信道数组、权重或实验输出，不需要Git LFS。
